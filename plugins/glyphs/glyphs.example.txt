# glyphs.txt: which title textures hold which pad button glyphs (docs/GLYPHS.md).
# Copy to <data>\glyphs\glyphs.txt (e.g. D:\dev\Vertex-AXX\data\glyphs\glyphs.txt).
# Read again within a second of a change; textures already on screen change the next time the game uploads them.
#
# <hash or dump file name>  <glyph>  [x y w h]  [menu] [premul]
#
#   glyph:  A B X Y LB RB LT RT View Menu L3 R3 DUp DDown DLeft DRight DPad LS RS LX LY RX RY
#           LSUp LSDown LSLeft LSRight RSUp RSDown RSLeft RSRight
#           key=<KeyName>   a key of your choosing (names as in native-keys.txt: Space, E, LeftClick, F5 ...)
#           label=<TEXT>    a cap with that text (letters, digits, punctuation)
#   x y w h: the glyph's rectangle in the dumped PNG (texels); leave out when the whole texture is the glyph
#   menu:   the key the button stands for in menus, not in play
#   premul: the texture has premultiplied alpha (try it if the caps' edges look dark or haloed)
#
# map <glyph> <KeyName> [menu]   overrides what native-keys.txt says for that button's caps
#
# Examples (the hashes are made up):
# 3fa2c9d1e0b4a785_64x64_BC3.png  A
# 9c01d2e3f4a5b6c7_256x64_BC7.png A    0 0 64 64
# 9c01d2e3f4a5b6c7_256x64_BC7.png B   64 0 64 64
# 9c01d2e3f4a5b6c7_256x64_BC7.png X  128 0 64 64
# 9c01d2e3f4a5b6c7_256x64_BC7.png Y  192 0 64 64
